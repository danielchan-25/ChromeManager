### 集成测试中发现并修复的问题

- Linux Chrome 会重写进程标题，psutil 可能按空格拆开原来的 `User Data` 参数；这曾导致自主重启后的接管失败以及 systemd 运行时转发误报进程身份不匹配。统一识别逻辑现在核对完整已知路径片段、目录 SingletonLock 的主机/PID，再结合进程创建时间和实际 CDP 身份确认，不接受目录前缀或仅端口匹配。
- 测试端口的 TIME_WAIT 被误当作真实监听冲突，已在测试中正确区分；实际公开端口被占用时仍报告错误并隔离重试。
- Chrome 桌面自主重启测试使用 Xvfb 下的有界面模式，覆盖正式部署方式。
